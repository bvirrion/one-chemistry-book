\section*{第 \ref{ch:g12:polymers} 章——聚合物}

\begin{solution}{exo:g12:polymers:1}
丙烯，\ce{CH2=CH-CH3}。
\end{solution}

\begin{solution}{exo:g12:polymers:2}
\ce{-CF2-CF2-}；\omterm{def:g12:polymers:addition-polymer}{加聚物}：\omterm{def:g12:polymers:polymer}{单体}含有 \ce{C=C} 键，
且不生成其他产物。
\end{solution}

\begin{solution}{exo:g12:polymers:3}
加聚：聚乙烯、PVC、聚苯乙烯。缩聚：PET（一种聚酯），
尼龙（一种聚\omterm{def:g11:functional-groups:amine}{酰胺}）。
\end{solution}

\begin{solution}{exo:g12:polymers:4}
纤维素、淀粉、天然橡胶（取自胶乳）、蛋白质。尼龙和 PVC 是
\omterm{def:g10:synthesis-yield:synthesis}{合成}的。
\end{solution}

\begin{solution}{exo:g12:polymers:5}
每个链节含有每种\omterm{def:g12:polymers:polymer}{单体}各一个\omterm{def:g11:functional-groups:functional-group}{官能团}；\omterm{def:g12:polymers:polymer}{单体}带两个\omterm{def:g11:functional-groups:functional-group}{官能团}时，
两侧都能成键，链条持续增长。只带一个\omterm{def:g11:functional-groups:functional-group}{官能团}的\omterm{def:g12:polymers:polymer}{单体}
会使链条终止。
\end{solution}

\begin{solution}{exo:g12:polymers:6}
$M(\ce{C2H3Cl}) = 24.0 + 3.0 + 35.5 = \qty{62.5}{g/mol}$；
$n = 125000/62.5 = 2000$。
\end{solution}

\begin{solution}{exo:g12:polymers:7}
$M(\ce{C8H8}) = \qty{104.0}{g/mol}$；$M = 2500 \times 104.0 =
\qty{2.60e5}{g/mol}$。
\end{solution}

\begin{solution}{exo:g12:polymers:8}
一个\omterm{def:g7:atoms-and-molecules:molecule}{分子}的羧基与相邻\omterm{def:g7:atoms-and-molecules:molecule}{分子}的醇羟基形成酯键，
而后者仍含游离羧基，链条持续增长。\omterm{def:g12:polymers:repeat-unit}{重复单元}
为\ce{-O-CH(CH3)-CO-}；每形成一个链节释放一\omterm{def:g7:atoms-and-molecules:molecule}{分子}水。
\end{solution}

\begin{solution}{exo:g12:polymers:9}
\omterm{def:g8:plastics:plastic}{塑料}袋薄膜由支化链构成，支链无法紧密堆积：材料
呈非晶态，柔软且透明。牛奶瓶由近似线性的链构成，
链可堆积成结晶区：密度更大，更坚硬，并且
结晶区会散射光。
\end{solution}

\begin{solution}{exo:g12:polymers:10}
这类材料的链之间由许多\omterm{def:g10:lewis-and-shape:covalent-bond}{共价键}交联。加热无法
使链发生滑移，反而会断开化学键、破坏材料，
而不会使其熔化。
\end{solution}

\begin{solution}{exo:g12:polymers:11}
$M(\ce{C12H22N2O2}) = 144.0 + 22.0 + 28.0 + 32.0 = \qty{226.0}{g/mol}$；
$n = 22600/226.0 = 100$。
\end{solution}

\begin{solution}{exo:g12:polymers:12}
\[
  \ce{H2N(CH2)6NH2 + HOOC(CH2)4COOH -> H2N(CH2)6NHCO(CH2)4COOH + H2O} .
\]
生成物的一端仍带有游离的氨基，另一端仍带有游离的羧基，
两端均可与另一\omterm{def:g12:polymers:polymer}{单体}继续反应。
\end{solution}

\begin{solution}{exo:g12:polymers:13}
每个\omterm{def:g12:polymers:repeat-unit}{重复单元}生成两\omterm{def:g7:atoms-and-molecules:molecule}{分子}水。$n = 1000/226.0 =
\qty{4.42}{mol}$ \omterm{def:g12:polymers:repeat-unit}{重复单元}，因此水的\omterm{def:g10:the-mole:amount}{物质的量}为 \qty{8.85}{mol}：
$8.85 \times 18.0 = \qty{159}{g}$。
\end{solution}

\begin{solution}{exo:g12:polymers:14}
温热的天然橡胶由可相互滑动的链构成。
硫桥将链连接起来：材料可拉伸并能回弹，且不再
流动。由于发生交联，轮胎无法熔化重塑。
\end{solution}

\begin{solution}{exo:g12:polymers:15}
$M(\ce{C6H10O5}) = \qty{162.0}{g/mol}$；$n = \num{1.6e6}/162.0 = 9900$
个链节；长度 $9900 \times 0.5 = \qty{4900}{nm}$，约为
\qty{5}{\micro m}。
\end{solution}

\begin{solution}{pb:g12:polymers:1}
\textbf{1.} 乙烷-1,2-二醇（含两个醇羟基）和
苯-1,4-二\omterm{def:g11:functional-groups:carboxylic-acid}{羧酸}（含两个羧基）。

\textbf{2.} 形成酯键，同时释放水。

\textbf{3.} \omterm{def:g12:polymers:addition-polymer}{缩聚物}。

\textbf{4.} $M(\ce{C2H6O2}) = \qty{62.0}{g/mol}$；$M(\ce{C8H6O4}) =

\textbf{5.} $62.0 + 166.0 - 2 \times 18.0 = \qty{192.0}{g/mol}$；且

\textbf{6.} $n = 38400/192.0 = 200$。

\textbf{7.} 每个\omterm{def:g12:polymers:repeat-unit}{重复单元}含两个酯键，共约 400 个。

\textbf{8.} 其链大多为线性结构，部分链段
排列成有序区。

\textbf{9.} 它是\omterm{def:g8:plastics:thermoplastic}{热塑性塑料}：其链之间没有交联，

\textbf{10.} $300/0.80 = \qty{375}{g}$。

\textbf{11.} $375/25 = 15$ 个瓶子。

\textbf{12.} 瓶盖、标签、污垢和碎屑在

\textbf{13.} 防止浪费（原则 1）：废弃物品变为
原料。

\textbf{14.} \ce{C10H8O4 + 2H2O -> C2H6O2 + C8H6O4}。

\textbf{15.} $1000/192.0 = \qty{5.21}{mol}$。

\textbf{16.} 二元醇：$5.21 \times 62.0 = \qty{323}{g}$；二元\omterm{def:g11:functional-groups:carboxylic-acid}{羧酸}：

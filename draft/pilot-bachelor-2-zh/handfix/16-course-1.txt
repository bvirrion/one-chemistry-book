20| \section{休克尔方法}
21| 
22| 在平面共轭分子中，$\sigma$ 轨道关于该平面对称，垂直于平面的 p
23| 轨道关于该平面反对称：二者互不混合
24| （\cref{prop:b2:diatomic-mos:symmetry}），因而可单独处理 $\pi$
25| 电子。
26| 
27| \begin{definition}[休克尔方法]\label{def:b2:huckel:method}
28| \emph{休克尔方法}\index{休克尔方法}用以计算平面共轭体系的 $\pi$ 轨道，
29| 即将其表示为每个原子一个 p 轨道的 $\psi = \sum_r c_r p_r$ 形式的线性组合，
30| 并采用以下近似：重叠积分 $S_{rs} = 0$（$r \neq s$ 时），$r =
31| s$ 时为 1；所有库仑积分均取为 $\alpha$；成键近邻之间的共振积分取为 $\beta < 0$，
32| 其余为零。
33| \end{definition}
34| 
35| 令 $x = (\alpha - E)/\beta$，则对每个原子 $r$，久期方程变为
36| $xc_r + \sum_{s \text{ 键合于 } r} c_s = 0$，
37| 能量即为以 $x$ 为对角元、成键原子间为 1 的行列式的根。等价地，$E =
38| \alpha + m\beta$，其中 $m$ 为该分子碳骨架邻接矩阵的本征值；
39| 由于 $\beta < 0$，正的 $m$ 对应成键能级。
40| 
41| \begin{method}[休克尔计算]\label{met:b2:huckel:huckel}
42| \begin{enumerate}
43|   \item 将共轭原子编号，写出矩阵：对角元为 0，
44|         成键的每一对原子处为 1。
45|   \item 求其本征值 $m_k$（用下面的闭合形式或数值方法）：$E_k =
46|         \alpha + m_k\beta$。
47|   \item 从最成键的能级起填充电子，每级两个电子：
48|         $E_\pi = \sum_k n_k E_k$。
49|   \item 由归一化系数计算电荷与键级。
50| \end{enumerate}
51| \end{method}
52| 
53| \begin{proposition}[迹]\label{prop:b2:huckel:trace}
54| 休克尔体系中 $n$ 个 $\pi$ 轨道的能量之和为 $n\alpha$。
55| \end{proposition}
56| 
57| \begin{proof}
58| 矩阵本征值之和等于其迹；休克尔矩阵以 $\alpha$ 为
59| 其全部 $n$ 个对角元。
60| \end{proof}

62| \section{线性多烯}
63| 
64| \begin{theorem}[线性链的能级]\label{thm:b2:huckel:polyene}
65| 含 $n$ 个原子的线性共轭链具有如下能级与系数：
66| \[
67|   E_k = \alpha + 2\beta\cos\frac{k\pi}{n + 1}, \qquad
68|   c_{jk} = \sqrt{\frac{2}{n + 1}}\,\sin\frac{jk\pi}{n + 1}, \qquad k = 1, \dots, n .
69| \]
70| \end{theorem}
71| 
72| \begin{proof}
73| 久期方程为 $c_{j-1} + xc_j + c_{j+1} = 0$，$j = 1, \dots, n$，
74| 且 $c_0 = c_{n+1} = 0$。试取 $c_j = \sin j\theta$：$\sin(j - 1)\theta + \sin(j + 1)\theta = 2\sin
75| j\theta\cos\theta$，故方程在 $x = -2\cos\theta$ 时成立，且 $c_0 = 0$
76| 自动满足。端点条件 $c_{n+1} = \sin(n + 1)\theta = 0$ 给出 $\theta =
77| k\pi/(n + 1)$。于是 $E = \alpha - x\beta = \alpha + 2\beta\cos\theta$。归一化时用到
78| $\sum_{j=1}^n\sin^2 j\theta = (n + 1)/2$。
79| \end{proof}

81| \begin{example}[丁二烯]\label{ex:b2:huckel:butadiene}
82| 当 $n = 4$ 时：$E = \alpha \pm 1.618\beta$，$\alpha \pm 0.618\beta$。四个 $\pi$ 电子填充两个
83| 成键能级：$E_\pi = 4\alpha + 2(1.618 + 0.618)\beta = 4\alpha + 4.472\beta$。最低
84| 轨道系数为 0.372、0.602、0.602、0.372，次低轨道为 0.602、0.372，
85| $-0.372$、$-0.602$。
86| \end{example}

108| \begin{definition}[$\pi$ 电荷与键级]\label{def:b2:huckel:indices}
109| 设 $n_k$ 为轨道 $k$ 中的电子数（取 0、1 或 2），$c_{rk}$ 为实系数，
110| \emph{$\pi$ 电荷}\index{$\pi$ 电荷}为原子 $r$ 上的 $q_r = \sum_k n_kc_{rk}^2$（即
111| 该原子所带的 $\pi$ 电子数），\emph{$\pi$ 键级}\index{$\pi$ 键级}
112| 键 $rs$ 的键级为 $p_{rs} = \sum_k n_kc_{rk}c_{sk}$。
113| \end{definition}
